# 요건사실론 기반 상담 수집·종료·요약 재설계

> 2026-08-17 확정. `docs/essential-facts.md`(요건사실론 제1장 요약)를 근거로
> 상담 챗봇의 되묻기·종료 판단·변호사 요약 보고를 요건사실론 구조로 재편한다.

## 배경

기존 챗봇은 "분야 / 입장 / 경위 / 진행 / 원하는 것" 5개 항목을 수집하고,
4개가 파악되면 종료했다. 그러나 이는 변호사가 소송에서 실제로 던질 질문
(요건사실 중심)과 괴리가 있다.

변호사는 권리·법률관계의 존부 판단을 위해 **① 권리근거사실**을 먼저 파악하고,
그 다음 **② 권리장애·소멸·저지사실**(상대방 반대측)이 있는지 확인하며,
**③ 증빙·간접사실**(서류·경위)로 사실관계를 뒷받침한다.

상담 챗봇도 같은 구조로 수집해야, 변호사가 받아보는 요약이 **소장/답변서
작성에 바로 쓸 수 있는 요건사실 중심**이 된다.

## 수집 요소 (4요소 구조)

| 요소 | 내용 | 대표 질문 |
|------|------|-----------|
| **① 의도(소구)** | 상담자가 원하는 바 — 권리를 발생시키고자 하는지, 소멸시키고자 하는지, 확인을 원하는지 | "이번에 원하시는 것이 무엇인가요?" |
| **② 권리근거사실** | 권리·법률관계 발생을 근거짓는 사실. 분야별 핵심 구성요건 해당 사실 | 교통사고: 사고 일시·상대·과실 경위 / 대여금: 차용·금액·변제기 등 |
| **③ 권리장애·소멸·저지사실** | 상대방이 반대할만한 사유 — 변제, 시효, 면제, 해제, 동시이행, 권리남용 등 | "상대방이 어떤 반대 주장을 할 것 같으신가요?" |
| **④ 증빙·간접사실** | 서류·증거·사건 경위 등 사실관계를 뒷받침하는 자료 | "관련 서류(차용증/소장/통지서)를 갖고 계신가요?" |

## 되묻기 (LLM 프롬프트)

- 시스템 프롬프트의 수집 항목을 위 4요소로 교체.
- 분야별 법적 쟁점 가이드는 **권리근거사실 추출** 관점으로 재정리.
- 질문은 여전히 **사실 질문 1개, 2~3문장 이내**. 법률 답변 금지 HARD 규칙 유지.

## 종료 판단

**턴 수 기반 강제 종료는 없다.** 요건사실을 수집할 때까지 대화가 이어진다.

- **충분히 수집 → 종료:** ①의도 + ②권리근거사실이 충분히 수집되면 종료(마감).
  → LLM이 마무리 의사를 감지해 "접수했습니다" 반환.
- **불충분하지만 더 수집 불가 → 종료:** ③④를 물었으나 사용자가 답을 못 하거나
  새 정보가 안 나오면(같은 맥락 2회) 그대로 종료. 부족한 부분은 요약 보고에
  "미확인/추가 확인 필요"로 표시해 변호사가 후속 조치하게 한다.
- **긴급:** 감지 시 즉시 접수.

### 안전망 (턴 수가 아닌 것들)

- **오픈빌더 콜백(useCallback)**: 대화가 길어져도 5초 timeout 걱정 없이
  백그라운드에서 처리된다. (`MAX_HISTORY`는 토큰 제한 대응용 안전 상한 60)
- **LLM 무응답/빈 응답 폴백**: 추론 체인 전부 실패 시 빠른 모델 → 고정 문구.
- **inflight TTL(60초)**: 처리 중 사용자가 계속 발화해도 플래그가 무한정 잠기지 않음.
- **되묻기 품질**: LLM이 "접수했습니다" 없이 계속 헛질문을 반복하면(같은 맥락 2회)
  프롬프트의 마감 규칙이 발동하도록 설계. 실무상 무한 대화는 요건사실 4요소가
  채워지면 종료되므로 대부분 짧게 끝난다.

## 요약 보고 (변호사 전달)

요약 JSON을 요건사실론 구조로 확장한다:

```
{
  "intent": "원하는 것(소구)",              // ① 의도
  "claim_facts": "권리근거사실(분야별 구성요건)",  // ②
  "defense_facts": "상대방 반대측(장애·소멸·저지)", // ③
  "evidence": "증빙·간접사실(서류·경위)",        // ④
  "missing": "미확인/추가로 파악 필요한 사항",     // 수집 불가분
  "field": "분야",
  "position": "입장",
  "urgent": false
}
```

- 알림 본문(`notify._format_message`)도 위 구조를 그대로 보여주어
  변호사가 소장/답변서 검토에 바로 쓸 수 있게 한다.
- `missing`(미확인 사항)을 명시해, 불충분하지만 종료한 경우 후속 확인을 돕는다.

## 분야별 권리근거사실 가이드 (프롬프트 주입)

| 분야 | 핵심 권리근거사실 |
|------|------------------|
| 교통사고 | 사고 일시·장소·상대방·경위, 과실 관계, 손해 항목(격락손해: 쿼터패널 판금 수리 여부) |
| 가정(이혼/상속) | 혼인/가족 관계, 이혼 사유·시점, 자녀, 재산·부채, 유언·상속인 |
| 부동산 | 계약 종류(매매/임대차), 체결 시점·금액, 계약금/중도금, 이행 여부 |
| 채권채무 | 채권자/채무자, 금액·이자, 변제기, 차용증·계약서 |
| 형사 | 고소인/피의자, 사건 유형, 수사 단계, 긴급성 |
