# 카카오톡 법률사무소 챗봇 — 설계 문서

> 작성일: 2026-08-07
> 상태: 초안 (사용자 리뷰 대기)

## 1. 목적

본인 법률사무소를 대표하는 카카오톡 1:1 채널 챗봇.
문의자의 법률 질의에 대해 **챗봇이 직접 답변하지 않고**, 충분히 되물어
모호성을 낮춘 뒤, 질의 내용을 요약해 **변호사에게 알림톡으로 전달**한다.

> ⚠️ **핵심 원칙 (법적 제약)**
> 챗봇이 법률 상담 답변을 직접 제공하면 **변호사법(무자격 법률사무취급)에 저촉될 수 있다.**
> 따라서 챗봇은 절대 법률 자문/답변을 하지 않는다.
> 챗봇의 역할은 **"질문을 정리해 변호사에게 전달하는 접수 채널"** 이다.

## 2. 채택 방식

**카카오 채널 + 카카오 i 오픈빌더(챗봇 빌더)** 를 사용한 공식 1:1 채널 상담 방식.

- 오픈채팅방이 아닌 **카카오 채널(챗봇)** 로 고객이 대화
- 비즈니스 인증 및 챗봇 심사 필요 (공식 API로 수신 → 시나리오/LLM 응답 → 전송)
- 제재 리스크가 낮고 안정적

## 3. 챗봇의 역할 (정의)

**챗봇은 법률 답변을 하지 않는다.** 다음 두 가지 역할만 수행:

### 3.1 질의 수집 (되묻기)

문의자가 법률 질문을 입력하면, 챗봇이 **충분히 되물어** 답변에 필요한 정보를 수집한다.

**되묻기 목표 — 모호성 최소화:**
- 상담 분야 (가정/부동산/채권채무/형사/노무/교통사고)
- 사건의 당사자 관계 (문의자가 어떤 입장인가: 원고/피고, 채권자/채무자 등)
- 사건의 핵심 사실과 경위 (무슨 일이 있었나)
- 현재 진행 상황 (소송 진행 중, 조정, 협의 중 등)
- 원하는 것 (무엇을 해결하고 싶은가)
- 관련 일시/금액 등 구체적 수치

**응답 패턴 예시:**
```
[문의자] 이혼하려고 하는데 어떻게 해야 하나요?

[챗봇] 사건 파악을 위해 몇 가지 여쭤보겠습니다.
1. 이혼 사유는 어떤 것인가요? (예: 배우자 부정, 폭력, 협의 이혼 등)
2. 협의 이혼이 가능한 상태인가요, 아니면 재판으로 진행할 예정인가요?
3. 자녀, 재산, 위자료 관련해서 알고 싶으신 부분이 있나요?
```

되묻기는 **한 번에 하나씩** 순차적으로 진행하며, 필요 정보가 충분히 모이면 다음 단계로 이동한다.

### 3.2 요약 전달 (변호사에게 알림톡)

모호성이 충분히 낮춰지면, 챗봇이 질의 내용을 **구조화된 요약**으로 만들어
**변호사(사무소)에게 알림톡으로 전달**한다.

전달받은 변호사가 그 내용을 바탕으로 직접 상담/답변을 진행한다.

## 4. 사용자 (고객) 흐름

고객이 카카오 채널에 접속하면 챗봇이 안내:

```
[첫 인사]
안녕하세요. ○○법률사무소입니다.
무엇을 도와드릴까요?

[메뉴]
1. 법률 상담 접수
2. 상담 예약 접수
3. 상담 절차 안내 (FAQ)
```

### 4.1 법률 상담 접수 (핵심)

1. 문의자가 법률 질문을 입력
2. 챗봇이 상담 분야를 파악 (필요 시 분야 선택 유도)
3. 챗봇이 **되묻기로 충분히 정보 수집** (한 번에 하나씩)
4. 정보가 모이면 질의 요약 생성 → **변호사에게 알림톡 전달**
5. 문의자에게 "질의를 접수했습니다. 변호사 확인 후 연락드리겠습니다." 안내

### 4.2 상담 예약 접수

고객이 다음 정보를 순차 입력:
1. 이름
2. 연락처
3. 상담 분야 선택 (가정/부동산/채권채무/형사/노무/교통사고)
4. 희망 날짜/시간

완료 시 → 예약 접수 완료 안내 (채팅 내) + **관리자 화면에 예약 신청 등록**

### 4.3 상담 절차 안내 (FAQ)

**법률 자문이 아닌 절차적/사무적 정보만** 안내:
- 상담 비용, 상담 절차, 방문 안내, 준비 서류, 연락처 등

> ⚠️ FAQ도 **법률 내용은 답하지 않는다.** 절차·비용·방문 등 행정 정보만 제공.
> 법률적 질문은 "상담 접수"로 유도한다.

## 5. 상담 분야 (기본 세트)

| 분야 | 주요 내용 |
|------|-----------|
| 가정 | 이혼, 상속, 가사 |
| 부동산 | 매매, 임대차, 명의신탁 |
| 채권/채무 | 대여금, 회수, 회생 |
| 형사 | 고소·고발, 피의자·피해자 변호 |
| 노무 | 근로계약, 해고, 임금 |
| 교통사고 | 손해배상, 형사처벌 대응 |

## 6. 예약 확정 흐름 (관리자 → 고객)

카카오 오픈빌더 챗봇은 **고객이 먼저 말을 걸어야 응답**하므로,
챗봇이 능동적으로 먼저 고객에게 메시지를 보낼 수 없다.

따라서 예약 확정/불가 안내는 **관리자 백엔드 + 알림톡(Alimtalk) 자동 발송**으로 처리한다.

```
고객 예약 접수 → 관리자 화면에 등록
                     │
        변호사(관리자)가 [확정] 또는 [불가] 버튼 클릭
                     │
                     ▼
       알림톡 자동 발송 → 고객 연락처
        - 확정: "상담 예약이 확정되었습니다. [날짜/시간]"
        - 불가: "해당 시간 예약이 불가하여 사무소에서 연락드리겠습니다."
```

- 변호사가 챗봇과 대화하는 대신 **버튼 하나**만 누르면 시스템이 고객에게 안내 발송
- 고객의 전화번호가 확정/불가 알림의 전송 대상

## 7. 관리자 화면

챗봇 운영 전용 **별도 웹 페이지** (간단한 관리자 사이트).

**화면 구성 — 상담 접수 탭:**
```
📋 상담 질의 접수
─────────────────────
[신규] 김○○ 010-1234-5678
      분야: 가정(이혼)
      ─ 질의 요약 ─
      "배우자 부정으로 이혼 고려 중. 협의 어렵고
        재산분할·자녀 양육 문의"
      [상담 시작] [예약 연결] [완료]
─────────────────────
```

**화면 구성 — 예약 신청 탭:**
```
📋 예약 신청 목록
─────────────────────
[신규] 이○○ 010-5678-1234
      부동산 · 8/13(목) 10:00
      [확정] [불가]
─────────────────────
```

- 상담 질의 접수 목록 확인 + 질의 요약 확인
- [확정] / [불가] 버튼 클릭 시 알림톡 자동 발송
- 사무소 PC/폰 브라우저에서 접속

## 8. 아키텍처

```
고객 카카오톡
    │
    ▼
카카오 채널 (챗봇) ── 카카오 i 오픈빌더 스킬/시나리오
    │                              │
    │ 시나리오 응답                │ 질의/예약 데이터 수신(웹훅/API)
    │ (되묻기/접수/안내)           ▼
    │                    백엔드 (저장소 + 알림톡 발송)
    │                              │
    │                              ▼
    │                    관리자 화면 (질의확인/확정/불가)
    │                              │
    │                              ▼
    │                    알림톡(Alimtalk) → 변호사(상담 접수)
    │                    알림톡(Alimtalk) → 고객(예약 확정/불가)
    └─────────────────────────────────────────────┘
```

- **오픈빌더**가 대화 시나리오(되묻기)와 절차 안내 처리
- **백엔드**가 질의/예약 데이터를 수신·저장하고, 관리자 화면 제공, 알림톡 발송
- **상담 질의 요약**은 변호사에게, **예약 확정/불가**는 고객에게 알림톡 전송
- 고객의 전화번호가 예약 확정/불가 알림의 전송 대상

## 9. 구현 단계 (향후)

1. 카카오 채널 생성 + 비즈니스 인증
2. 카카오 i 오픈빌더 챗봇 생성 및 시나리오 설계
3. **되묻기(질의 수집) 시나리오 설계** — 분야별 되묻기 질문 목록
4. 백엔드 구축 — 질의/예약 저장소 + 관리자 화면 + 알림톡 연동
5. 오픈빌더 ↔ 백엔드 연동 (질의/예약 데이터 수신)
6. 절차 안내(FAQ) 콘텐츠 작성
7. 심사 제출 및 운영

## 10. 비고
- **법률 자문 금지**: 챗봇은 어떤 경우에도 법률 답변/자문을 직접 제공하지 않음
- 챗봇 역할 = 질의 수집(되묻기) + 요약 전달(변호사 알림톡) + 절차 안내
- 변호사가 질의 요약을 보고 직접 상담 진행
- 예약 확정/불가 결정은 사무소 담당자(변호사)가 관리자 화면에서 수행
- 질의 요약 전달 시 문의자 연락처 포함 (변호사가 회신할 수 있도록)
